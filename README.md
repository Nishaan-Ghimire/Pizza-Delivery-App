# Pizza-Delivery-App

Welcome to the Pizza-Delivery-App! This project is a web application for ordering delicious pizzas online. It is built using Node.js, Express.js, MongoDB, and EJS for templating.

## Features

- User Authentication (Sign Up / Login)
- Pizza Menu Browsing
- Adding Pizzas to Cart
- Order Placement
- Order Tracking
- Admin Dashboard for Managing Orders

## Installation

Follow these steps to get the Pizza-Delivery-App up and running on your local machine.

### Prerequisites

Make sure you have the following installed:

- [Node.js](https://nodejs.org/)
- [MongoDB](https://www.mongodb.com/)


# Pizza-Delivery-App

Welcome to the Pizza-Delivery-App! This project is a web application for ordering delicious pizzas online. It is built using Node.js, Express.js, MongoDB, and EJS for templating.

## Features

- User Authentication (Sign Up / Login)
- Pizza Menu Browsing
- Adding Pizzas to Cart
- Order Placement
- Order Tracking
- Admin Dashboard for Managing Orders

## Installation

Follow these steps to get the Pizza-Delivery-App up and running on your local machine.

### Prerequisites

Make sure you have the following installed:

- [Node.js](https://nodejs.org/)
- [MongoDB](https://www.mongodb.com/)

### Clone the Repository

```bash
git clone https://github.com/Nishaan-Ghimire/Pizza-Delivery-App.git
cd Pizza-Delivery-App
npm install

```

### Environment Variables
 Create a .env file in the root directory and add the following environment variables:

```bash
PORT=3000
MONGO_URI=your_mongodb_connection_string
SECRET=your_secret_key
```

```bash
npm start
```
